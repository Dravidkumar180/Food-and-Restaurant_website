# FoodieHub translations

English is the authored source. Tamil and Hindi catalogs cover the six pages, shared navigation/footer, image descriptions, form labels, and interaction messages. Editorial text was machine translated during development; essential navigation and form labels were reviewed and overridden locally. A native-language editorial review is recommended before relying on nuanced food descriptions.

All translations are bundled in `translations.js` and run locally. The live site makes no translation-service requests and does not transmit visitor form entries for translation. Product identifiers, prices, promotion codes, and user-entered form values remain intact.
